# Palworld Companion

A mobile-first Palworld companion app built with React, TypeScript, and Vite for GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This repository includes a GitHub Actions workflow that builds and deploys the app to GitHub Pages when changes are pushed to `main`.

In GitHub, enable **Pages** for the repository and select **GitHub Actions** as the source.

## Data status

The current dataset is an imported Palworld companion dataset with some areas still being verified. Missing or unverified game information is shown as unavailable rather than guessed.
